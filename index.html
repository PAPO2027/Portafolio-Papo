Proyecto 1 — Snake Evolution

Videojuego

Un juego inspirado en Snake donde el jugador controla una serpiente, recoge gallinas, aumenta su puntuación y avanza por niveles de dificultad. Está pensado para quienes disfrutan de retos arcade.

¿Cómo está hecho?

Está desarrollado con HTML, CSS y JavaScript, y publicado mediante GitHub Pages. JavaScript se ejecuta en el navegador y controla el movimiento, las colisiones, los niveles, las vidas y los potenciadores. No usa una base de datos; el récord se mantiene durante la sesión.

Proyecto 2 — MESA 8

Multijugador

Un juego de billar multijugador inspirado en 8 Ball Pool, donde dos jugadores pueden compartir una partida, tomar turnos y competir siguiendo las reglas del juego.

¿Cómo está hecho?

El proyecto utiliza Vercel para publicar la aplicación y Supabase Realtime para sincronizar información de la partida entre jugadores. La lógica y las físicas se ejecutan en el navegador; la comunicación en tiempo real comparte el estado del juego. La autenticación se trabajó con Supabase Auth, mientras que algunas estadísticas y monedas se guardan localmente mediante localStorage.
